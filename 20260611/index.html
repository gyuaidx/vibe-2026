✨ 공정 등급 드래프트 (Equal Rarity Draft)

  • 확률: 일반(Bronze 50%) / 희귀(Silver 40%) / 전설(Gold 10%)
  • 드래프트 시 모든 플레이어에게 동일한 등급의 카드 3장이 무작위 제시됩니다.
  • 리롤(Reroll): 선택 시마다 1회의 리롤 기회가 주어지며, 동일 등급 내에서 새 카드로 갱신됩니다.
  • 타이밍: 게임 시작 직전(1회차) 및 모든 플레이어 진행 턴 합 6턴 단위마다 추가 드래프트!

🏆 7가지 특수 승리 조건

  • 백도의 암살자: 백도로 상대 말을 2개 잡을 시 즉시 승리
  • 현상금 사냥꾼: 상대 말을 통산 5번 잡을 시 즉시 승리
  • 윷놀이의 달인: 백도/도/개/걸/윷/모를 모두 1회씩 던지면 즉시 승리
  • 야옹이의 보은: '고양이' 보유 중 선택 시 즉시 승리
  • 영웅의 출격: 영웅으로 지정된 말이 완주 시 즉시 승리
  • 칠전팔기: 내 말이 통산 7번 잡힐 시 즉시 승리
  • 오뚝이의 집념: 내 말이 통산 12번 잡힐 시 즉시 승리
